# Design references for this site

Restyle only within these rules:

1. Anthropic "frontend-design" skill — one typeface, hierarchy by weight, no all-caps labels, no card-per-item SaaS kit, no decorative chrome; spend boldness in one place.
2. Emil Kowalski's Apple design skill — https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md — feedback on pointer-down, spring curves, system fonts, translucent materials, respect reduced motion.

Current choices (style.css): light Apple-grey page, white grouped lists with hairline dividers, segmented-control tabs, one blue accent, tier colour carried by a dot not the heading.
