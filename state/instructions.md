## Sources
- Reliable sources only. Primary sources (official blogs, papers, repos, press releases) preferred.
- No Medium posts, SEO farms, or social-media rumours as the sole source.

## Rules
- Never repeat an item already listed in state/seen.md. A follow-up to an old item is fine only if there is real new information — say what's new.
- Tag every item Confirmed (primary source) or Reported (2+ reliable outlets). Nothing Reported goes in Must See.
- Never pad. Empty tier = "Nothing today".
- Never invent URLs.
